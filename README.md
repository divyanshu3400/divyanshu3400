### 🏭 **Kashee Dairy ERP** — Enterprise Platform Serving 14,000+ Daily Users

> **Tech Stack:** Django DRF · Celery · Redis · MSSQL · WebSockets · React · Windows Server · Ubuntu

I designed, built, deployed, and maintain the **entire backend** for this enterprise ERP system **100% solo**.

#### What It Does
- Complete inventory management for a dairy operation
- HR and payroll processing for field staff
- Veterinary and milk collection tracking
- Real-time field communication across 14,000+ daily users

#### Technical Highlights
- **50+ REST API endpoints** (part of 250+ total APIs across my projects)
- **100× API optimization** — reduced response times from 21 seconds to 200ms through:
  - Redis caching strategy
  - ORM query restructuring
  - Database indexing optimization
  - MSSQL stored procedures for complex reporting
- **Server-Driven UI Engine** — DRF's OPTIONS endpoint drives React form generation dynamically
  - Result: **60% reduction** in frontend development time
  - Single source of truth for form validation and UI logic
- **10,000+ row Excel imports** — Celery workers handle batched processing without blocking
- **JWT + RBAC** — Multi-tenant data isolation enforced at ORM level
- **Production reliability** — 99.8% uptime, handling peak loads of 500+ concurrent users
